## 本地使用方法

打开html文件即可。


> 注意：从网盘下载的视频和html同级



## 服务器公网演示使用方法

使用如下命令启动

```bash
node run.js
```

会在13733端口上打开一个网站，即可进行播放。

视频播放会进行完整缓存。若在播放过程中修改视频，请务必缓存！

> 注意：从网盘下载的视频需要存在`show`目录下
